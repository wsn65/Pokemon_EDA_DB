# Pokémon Data Exploration & Interactive Dashboard

Project Overview

This project explores a Pokémon dataset using Exploratory Data Analysis (EDA) techniques and presents the findings through an interactive dashboard built with Streamlit.

The goal is to identify patterns, understand Pokémon characteristics and explore relationships between battle statistics and other attributes.

Dataset:

Source: TidyTuesday – Pokemon Dataset

Records: 949 Pokemon

Features: Pokemon types, physical characteristics, battle statistics, base experience, and egg groups.

Dashboard Features

The interactive dashboard includes:

Overview: Dataset preview and summary statistics.

Pokémon Types: Explore Pokemon type distributions.

Battle Statistics: Analyze battle stats and their distributions.

Base Experience: Explore relationships between base experience and battle statistics.

Physical Characteristics: Explore Pokemon height and weight.

ML Model: Predict Base Experience using Linear Regression.
